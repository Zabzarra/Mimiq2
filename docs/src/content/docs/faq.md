**Can Mimiq withdraw my funds?** No. Mimiq never holds your funds. The keys you link are for trading only.

**What does it cost?** Mimiq takes 1 bp (0.01%) of trade value on most venues. The venue's own fees come on top. See [Fees](/fees/).

**Do I need an invite?** Yes. Join the waitlist in the bot if you have no code.

**Which venues?** 11. See [Supported venues](/venues/).

**Can I run copy trading and delta-neutral at the same time?** One wallet runs one mode at a time. Use several wallets to run both.

**What if one leg of a pair is liquidated?** The hedge guard closes the other leg and notifies you.

**What is the minimum order?** 10 USD. On RiseX, Hibachi and Extended 1 USD.

**Does Mimiq promise returns?** No. See [Risks](/risks/).
